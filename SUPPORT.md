# Getting help

| You want to… | Go to |
|---|---|
| Ask a question or share an idea | [Discussions](https://github.com/bighnesh0007/dwcode/discussions) |
| Report a bug in the app | [New issue → Bug report](https://github.com/bighnesh0007/dwcode/issues/new/choose) |
| Say a specific problem's expected output is wrong | The **Report an issue** button on that problem |
| Propose a new problem | [New issue → New problem](https://github.com/bighnesh0007/dwcode/issues/new/choose) |
| Report a security vulnerability | **Privately** — see [SECURITY.md](SECURITY.md). Never in a public issue. |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

DWCode is maintained by volunteers. Issues are triaged roughly weekly; security
reports get priority.
